# 山海之间 · SHAN HAI

基于《山海经》的交互式神话地理舆图与 3D 沉浸体验。

**在线体验：** https://noname4me.github.io/shan-hai/

## 当前进度：V1.0

- **十八卷目录与神话舆图**：按卷查看地点锚点、原文摘录、方位关系和出处。
- **五藏山经路线**：建立五卷 26 段路线索引，当前录入 449 个路线节点，其中包含水行、流沙等 2 条独立特殊路段记录。
- **异兽图鉴**：15 条文本记录，支持关键词搜索和类别筛选。
- **山川水系**：45 条水源、流向、注入水域及山地关联记录。
- **山产志**：33 条植物、矿物与动物物产记录。
- **山中祀典**：26 段路线的神形、牲礼、玉帛、糈米和特殊祭法摘要，并提供基于摘要的要素拆分。
- **关系图谱**：由路线、水系、山产、异兽和祀典数据生成节点与关系，可从任一实体逐层探索；支持从神话事件与人物谱系定位到指定节点。
- **神话脉络探索（V1.0 第一阶段）**：新增神话事件线与人物谱系两个视图，按篇章组织事件，筛选原文明确支持的生育、婚配、子孙关系；事件、人物可跳转关系图谱。篇章顺序不等同于历史年代。
- **舆图—图谱双向联动**：地点详情可打开对应知识图谱节点；对具有舆图锚点的图谱节点，可返回舆图并自动选中地点。山经地点按篇章与山名匹配路线节点，海经地点使用独立地理锚点。
- **海外四经实体库**：结构化录入海外南、西、北、东四经 113 个实体与 106 条原文方位/叙事关系，覆盖古国、异人、神祇、异兽、神木、地理区域和神话事件；保留异文与出处。
- **海内四经实体库**：首批结构化录入海内南、西、北、东四经 196 个实体与 128 条文本关系，重点整理昆仑诸水、河流源流、古国、异兽、神祇和神话人物；对疑似错简与篇章移置保留校注提示。
- **大荒四经实体库**：结构化录入大荒东、南、西、北四经 392 个实体与 163 条文本关系，覆盖日月运行、帝俊与颛顼谱系、古国、神祇、异兽、神木和神话事件；将夸父逐日、羿杀凿齿、夏后开登天、女魃止雨等事件独立建档。
- **海内经综合篇实体库**：第十八篇首批录入 176 个实体、167 条篇内文本关系和 12 条跨卷关联，覆盖黄帝、颛顼、帝俊、炎帝等谱系，巴人起源、舟车与乐舞起源、洪水与鲧禹治水，以及相关山川、古国、异兽和物产。
- **跨卷实体索引**：对黄帝、颛顼、帝俊、后稷、羿、舜、叔均等有明确文本依据的人物建立共享节点；对朝鲜、窫窳、祝融、鲧、若木、三身等同名或谱系存在差异的条目保留独立节点并建立待校关联。
- **3D 试境**：青丘之山，使用 Three.js / React Three Fiber；暮色低多边形场景，支持环视、缩放、点击九尾狐查看文献；WebGL 不可用时提供同色板二维回退。
- **浏览状态**：模块切换保留筛选、选中项与图谱节点；路线中的水系、物产、异兽、祀典可直接定位到对应条目。
- **性能**：3D、图谱与资料模块按需加载，首页不下载 Three.js；提供资料加载失败重试与 3D 回退。

**范围声明：** V0.9 在海外四经、海内四经和大荒四经基础上，完成第十八篇《海内经》首批实体关系录入。海外四经 113 个实体、106 条关系；海内四经 196 个实体、128 条关系；大荒四经 392 个实体、163 条关系；海内经综合篇 176 个实体、167 条篇内关系及 12 条跨卷关联。实体清单不是全卷所有词项的穷尽抽取；关系只记录底本文字明确支持的方位、源流、谱系或叙事联系。异文、同名异物、不同谱系与指代歧义均保留待校，不伪装成精确坐标。跨卷关联不等于自动合并实体。449 个路线节点包含特殊路段，不能直接视为 449 座已考定的独立山体。

## 技术栈

React 19 + TypeScript + Vite + Three.js + React Three Fiber + Drei + GSAP + Zustand。无后端、无 3D CDN 依赖。

## 数据原则

1. 原文山名、方向、里程、物产、水系、异兽和祭祀记录与网页视觉坐标分开保存。
2. “又东/西/南/北若干里”作为相邻路线关系；水行、流沙等特殊路段保留原文，不强行折算为陆路里程。
3. 篇末山数、总里程与逐段提取结果分别保存。出现差异时标记待校勘，不擅自改写原文。
4. 同名异物、异文和不同篇章的同名地点分别建档；例如《南山经》的“青丘之山”与《海外东经》的“青丘国”不直接合并。
5. 水名按出水山、流向、注入水域和篇章分开建档；同名水流不自动合并。
6. 古代物产名称不直接套用现代物种鉴定；古籍中的食用、疗效和征兆记载不作为现代科学结论。
7. 祭祀数据仅作古籍制度史整理，不构成现实祭祀建议。

路线抽取范围、篇末总计核对、物产和水系数据约定见 [docs/ATLAS_DATA.md](docs/ATLAS_DATA.md)。

npm install
npm run dev
npm run build
\`\`\`

## GitHub Pages 部署

默认分支为 \`master\`，工作流位于 \`.github/workflows/deploy.yml\`。

1. 仓库 Settings → Pages → Build and deployment，Source 设为 **GitHub Actions**。
2. 推送到 \`master\` 后自动安装依赖、执行 \`npm run build\` 并发布 \`dist\`。
3. 站点地址：https://noname4me.github.io/shan-hai/ 。

Vite 构建时设置 \`GITHUB_PAGES=true\`，自动采用 \`/shan-hai/\` 基础路径。
