# 山海之间 · SHAN HAI

基于《山海经》的原生 Three.js 第一人称水墨科幻漫游场景。

**在线体验：** https://noname4me.github.io/shan-hai/

## 当前版本：V2.1 青丘第一人称重构

- **第一人称自由探索**：`WASD` 移动、`Shift` 疾行、`Space` 跃起；鼠标拖动环视、滚轮调整视野。玩家没有可见角色模型，镜头就是探索者本人。
- **程序化开放地形**：约 380×380 的连续山地，带高度采样、坡度阻挡、浅水区、环形群山、机械天关、九尾祭坛、赤色裂隙、树木、岩石、草叶、浮空残骸与实例化植被。
- **巨型机甲九尾**：骨白复合装甲、黑曜关节、朱砂接缝、九条独立发光尾刃、悬空符文环与尾尖感应光。靠近后按 `E` 或点击可打开《南山经》原文。
- **水墨科幻氛围**：着色器天空、黑云与星野、中央月轮、体积雾幕、低空流雾、浮尘、冷暖逆光、程序化水面、地形等高线与轻量 Bloom。
- **游戏化 HUD**：区域名、坐标、速度、海拔、罗盘、雷达、目标距离、交互提示、加载百分比与低帧率自动降级。
- **零外部视觉资源**：所有模型、材质、纹理与天空均由 JavaScript / Canvas / GLSL 实时生成，不引用外部图片、模型、字体或 CDN。

## 操作

| 输入 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 前后左右移动 |
| `Shift` | 疾行 |
| `Space` | 跃起 |
| 鼠标拖动 | 第一人称环视 |
| 滚轮 | 调整视野焦距 |
| `E` / 点击九尾或刻石 | 阅读文献 |
| `Esc` | 关闭文献面板 |

顶部“鸣啸”按钮会触发展尾演出。接近九尾祭坛后，界面出现交互提示。

## 技术栈

Three.js + 原生 JavaScript + Vite。无 React、无 UI 框架、无后端、无外部模型或贴图。

### 模块

- `src/qingqiu/terrain.js`：大地形高度函数、地表着色与等高线。
- `src/qingqiu/sky.js`：云层、星野、月轮与极光着色器。
- `src/qingqiu/distantPeaks.js`：四层程序化环形山脊。
- `src/qingqiu/water.js`：程序化水面、月面反射与发光水纹。
- `src/qingqiu/architecture.js`：九尾祭坛、天关、浮空环、路标与刻石。
- `src/qingqiu/rift.js`：赤色地脉裂隙与局部灯光。
- `src/qingqiu/foliage.js`：实例化树木、岩石与草叶。
- `src/qingqiu/atmosphere.js`：云幕、低空雾、浮尘、月晕与体积光柱。
- `src/qingqiu/fox.js`：机甲九尾的材质、壳体、四足、九尾与演出。
- `src/qingqiu/firstPerson.js`：第一人称移动、跳跃、坡度阻挡、视角与镜头呼吸。
- `src/qingqiu/postprocessing.js`：轻量 Bloom 与最终色彩输出。
- `src/qingqiu/qingqiu.js`：场景装配、拾取、HUD 数据、自适应画质与生命周期。
- `src/main.js`：原生 DOM 界面、雷达、加载、文献面板与 WebGL 回退。

视觉规则与性能预算见 [沉浸式场景视觉规则](docs/VISUAL_SYSTEM.md)。

## 性能策略

- 运行时仅依赖 Three.js。
- 树木、岩石与草叶使用 `InstancedMesh`，地形、山脊、尾刃各自合并为单一几何。
- 像素比上限 1.5；连续低帧率时降为 1，并关闭 Bloom 与实时阴影。
- 天空、地形、水面、雾和粒子均使用低成本程序化着色器。
- 分阶段生成场景并显示加载进度，避免白屏等待。
- WebGL 不可用或上下文丢失时进入二维概念回退页，并提供重新检测。

生产构建体积在发布记录中更新；Three.js 主包自身仍会触发 Vite 的 500 kB 体积提示。

## 数据原则

1. 原文山名、方向、里程、物产、水系、异兽和祭祀记录与网页视觉坐标分开保存。
2. “又东/西/南/北若干里”作为相邻路线关系；特殊路段保留原文，不强行折算为陆路里程。
3. 同名异物、异文和不同篇章的同名地点分别建档；《南山经》青丘之山与《海外东经》青丘国不直接合并。
4. 场景是依据文本意象的艺术重构，不是古代地理形貌的写实复原。
5. 古籍中的食用、疗效和征兆记载不作为现代科学结论。

旧版资料模块数据约定见 `docs/ATLAS_DATA.md`。React 版本保留在 Git 历史及本地 `.archive/react-v0/`，后者不进入版本控制或当前构建。
