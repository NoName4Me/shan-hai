## 3. 数据结构

- \`src/data/mountainRoutes.ts\`：V0.3 首批路线数据与公共类型定义。
- \`src/data/mountainRoutesV04.ts\`：补齐其余 21 段路线，形成五卷 26 段路线索引。
- \`src/data/waterways.ts\`：45 条水系关系，包含水名、关联山、出水/临水关系、流向、注入水域和原文链接。
- \`src/data/mountainResources.ts\`：33 条山中植物、矿物、动物与其他物产记录。
- \`src/data/mountainRituals.ts\`：26 条路线篇末祠礼摘要，保留神形、牲礼、玉帛、糈米和特殊冢祭。
- \`src/data/bestiary.ts\`：15 条异兽文本记录。

路线节点使用稳定 ID；水系和物产记录通过山节点 ID 关联。水名相同但出水山或篇章不同的记录分开保存，不自动合并。

## 4. 水系数据原则

1. “水出焉”记为发源关系；“北临某水”记为临水关系，不擅自改成源头。
2. “东流注于……”按原文记录流向和注入水域。
3. 水行、流沙、潜行等行程与陆路里程分开，不折算成直线距离。
4. 同名水流按篇章和出水山分别建档。例如不同山地所出的“英水”不自动合并。
5. 古代水名不直接等同于现代河流，也不作为现代水文学结论。

## 5. 山产数据原则

物产条目只记录原文明确出现的植物、矿物、动物或其他物产名称。古籍中的食用、药效、征兆与神异描述属于文本内容，不作为现代科学或医学结论。古今名称对应关系需另行考证。

## 6. 祀典数据原则

祀典按路线段篇末记载建立 26 条记录。牲礼、玉帛、糈米、冢祭和特殊神祭分别摘要；篇末未载的段落明确标注“未载”，不补造仪式。摘要不构成现实祭祀建议。

## 9. V0.5 关系图谱

- `src/data/knowledgeGraph.ts` 从现有路线、水系、物产、异兽和祀典数据生成节点与关系。
- 山与相邻山之间建立路线边，边标签保留方向和里程文字。
- 山与水之间建立“发源/临水”关系；水与承接水域之间建立“流向注入”关系。
- 山与物产、异兽之间建立“记有物产/见于”关系。
- 路线起点与篇末祀典建立关联；神形记录单独建档，并明确标注“非神名”，不从外形描述臆造神祇身份。
- `src/components/KnowledgeGraph.tsx` 提供搜索、类别筛选、逐层点击和原文查看。当前使用以所选实体为中心的局部关系视图，避免一次性绘制数百节点造成不可读的毛线团。

图谱的边是文本证据关系，不代表现代地理位置、物种亲缘或历史祭祀实践。

### 关系与异文原则

- 方位关系沿用原文“在其东/北/南”等表达，不将其换算为经纬度或现代地图坐标。
- 只有原文明确的地点、方位或叙事联系才建立实体边；章节先后仅在标签中明确注明“篇章接续”。
- “其北”等指代对象存在歧义时，关系标签明确标注“指代待校”，不把推断包装成确定事实。
- 同名/近名实体按篇章拆分，例如南山经的青丘之山与海外东经的青丘国；海外东经的汤谷与扶桑分别建为水域、神木。
- 异文记录在实体 note 中保留，如讙头/讙朱、周饶/焦侥、雒棠/雄常等；不将异文自动当作独立实体。
- 羿与凿齿之战、夸父逐日等事件单独建档；夸父与夸父国不合并。

原文来源均链接至对应维基文库篇章：海外南经、海外西经、海外北经、海外东经。该索引是文本关系网络，不代表现代地理复原、物种鉴定或神话人物之间的历史谱系结论。
