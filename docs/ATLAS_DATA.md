# 舆图数据约定（V0.2）

## 目标

将《山海经》的文本结构与网页视觉坐标分离。原文中可确认的方向、里程、相邻关系作为文本证据保存；网页中的 x/y 仅负责排版，不代表经纬度或历史地理复原。

## 数据层

- `chapters`：十八卷目录，保留通行本卷序。
- `chapterGroups`：山经、海外、海内、大荒、海内经五个导航分组。
- `locations`：当前已录入的关键地点锚点。
- `routeId / routeOrder / distanceFromPreviousLi`：表达原文明载的相邻行进次序、方向和里程。
- `quote / sourceUrl`：短引文与对应原文页面。
- `sceneId`：地点与已实现 3D 场景的关联。

## 当前可核对的地点关系

### 南山经：基山 → 青丘之山 → 箕尾之山

- 基山条目记“又东三百里”。
- 青丘之山条目记“又东三百里”，并记九尾狐、英水。
- 箕尾之山条目记“又东三百五十里”。
- 地图用金色虚线表示这三个节点的原文相邻关系。虚线在画面上的长度不是里程比例。

原文：[维基文库《山海经·南山经》](https://zh.wikisource.org/zh-hans/南山經)

### 海外东经：青丘国、汤谷与扶桑

- 青丘国在前文所述朝阳之谷以北，原文另有异文。
- 汤谷上有扶桑，十日所浴；原文称其在黑齿之北。
- 青丘国与南山经的青丘之山分属不同篇章，不能仅凭名称相同就合并为同一地理实体。

原文：[维基文库《山海经·海外东经》](https://zh.wikisource.org/zh-hans/山海經/海外東經)

### 海外北经：钟山

- 钟山之神名烛阴，原文称其居钟山下，并记钟山在无启之东。

原文：[维基文库《山海经·海外北经》](https://zh.wikisource.org/zh-hans/山海經/海外北經)

### 海内西经：昆仑之虚

- 原文称“海内昆仑之虚，在西北，帝之下都”，并描述其方八百里、高万仞。

原文：[维基文库《山海经·海内西经》](https://zh.wikisource.org/zh-hans/山海經/海內西經)

### 大荒西经：不周

- 原文称其位于“西北海之外，大荒之隅”。

原文：[维基文库《山海经·大荒西经》](https://zh.wikisource.org/zh-hans/山海經/大荒西經)

## 证据分级

1. **原文路线节点**：原文明确给出“又东/西/南/北若干里”等相邻路线信息。
2. **原文相对方位**：原文给出“在其北”“在某地之东”等关系。
3. **原文区域描述**：原文只给出“西北海之外”“大荒之隅”等宏观区域。
4. **现代地理比定**：需要独立的历史地理研究支持；当前版本不主动做此类比定。

当前仅为首批锚点与十八卷目录。未录入的卷目不能视为已完成全文地名抽取。
