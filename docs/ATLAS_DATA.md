# 舆图与山经数据约定（V0.3）

## 1. 数据范围

V0.3 为五藏山经五卷各录入一个首段路线，共 80 个具名节点；每个节点保留原文行进方向和逐段里程。它不是五藏山经全部路线的完整抽取。

异兽图鉴目前收录 15 条与这些首段路线有关的文本记录。图鉴不是《山海经》全书异兽全集。

## 2. 数据结构

- \`src/data/mountainRoutes.ts\`
  - \`mountainRoutes\`：五卷山经首段路线。
  - \`nodes\`：路线节点，保留山名、方向、与前一节点之间的里程、关联异兽 ID。
  - \`reportedMountainCount / reportedTotalLi\`：篇末原文汇总。
  - \`sumOfRecordedIntervalsLi\`：当前逐段数据的程序计算值。
  - \`auditNote\`：汇总与逐段数据不一致时的校勘说明。
- \`src/data/bestiary.ts\`
  - \`bestiary\`：异兽、鸟、鱼、龟等文本条目。
  - 每条记录包含经卷、所在山名、形态摘要、原文短引、出处和考据备注。
- \`src/atlas.ts\`
  - 十八卷目录、跨海经地点锚点和地图 UI 的示意坐标。

## 5. 考据与地图表达边界

1. “又东/西/南/北若干里”只说明文本中的相邻行进关系，不直接对应现代道路或经纬度。
2. 网页中的 x/y 是排版坐标，不是地理测绘坐标。
3. 原文中的“山”“国”“谷”“水”分属不同实体类型；同名不代表同一地点。
4. 同名异兽需要按篇章、形态、出现场景分别记录。例如英山的鸟形“肥遗”不与其他篇章的蛇形“肥遗”合并。
5. 后世注释、现代复原和原文记载需要分层展示，不将注家解释伪装成经文原句。
