# 山海之间 · 青丘视觉与实现规则

> 适用版本：V2.1。场景为《南山经》青丘之山／九尾狐的第一人称程序化重构。
> 本文记录当前实现与后续场景可复用的规则，不是对《山海经》生物外形的统一模板。

## 美术方向

**水墨 + 科幻机甲。**

水墨负责空间节奏：深靛留白、层叠山脊、雾幕、月轮、墨色地表与高对比剪影。机甲负责结构可信度：复合壳体、关节、接缝、能量回路、悬空环、遗迹几何与冷光仪表。

两者只在体块、轮廓与动势上融合。避免把电路纹、发光格栅和科幻 HUD 铺满所有物体。

## 空间与构图

- 第一人称相机默认位于青丘南麓，视线朝北，九尾祭坛与机械天关位于画面中央偏远处。
- 近景保留岩石、草叶与暗部；中景放置祭坛、路标和九尾；远景使用四层山脊与云幕，形成明确纵深。
- 月轮位于九尾后方偏上，形成逆光轮廓。月轮和天关拱门不得完全遮住九尾主体。
- 默认视距下九尾高度约占画面 20%–35%；接近祭坛后应可清楚分辨九尾、尾刃与四足。
- HUD 位于四角，不覆盖中心交互区。文献面板为右侧非阻塞浮层。

## 世界地形

`terrain.js` 是唯一高度采样入口，地形网格、玩家移动、放置植被、建筑与裂隙均调用同一个 `sampleTerrain(x, z)`。

- 世界约 380×380，边界由环形高山限制。
- 南侧出生台地平坦；中部古径通向九尾祭坛；东侧低洼处形成浅水泽。
- 地形坡度参与移动阻挡，玩家不能直接攀上陡壁。
- 地表颜色由高度、坡度和程序噪声混合，并使用世界坐标等高线与细尘纹理。
- 水面以下仍允许浅水行进，不增加独立游泳系统。

## 九尾狐

**原文锚点**：《南山经》“又东三百里，曰青丘之山……有兽焉，其状如狐而九尾，其音如婴儿，能食人；食者不蛊。”

视觉为艺术重构，不代替原文，也不与《海外东经》青丘国合并。

### 形体与辨识

- 狐首、颈、胸、腰、四足始终可辨；壳体使用连续放样与切面，而不是简单方块堆叠。
- 头部包含放样头骨、眉骨、长吻、下颌、颊甲、外倾耳和朱砂额印。
- 躯干为前后收分的复合装甲；四肢为髋／膝／踝三段机械结构。
- 九条尾刃从尾根扇形展开，各自拥有独立 Catmull-Rom 曲线、长度、粗细与动画相位。
- 尾刃以骨白为主体、内层墨黑，尾缘交替使用朱砂与冷青；每条尾尖设置感应光，保证远景可数清九条。
- 尾根粗、尾腹宽、尾尖收锋，不使用圆管或整排羽片。

### 材质

- 骨甲：Canvas 程序化墨纹 + 骨白，粗糙度约 0.42，金属度约 0.48。
- 黑曜石：低粗糙度、高金属度，仅用于关节与内层。
- 朱砂：低自发光，作为接缝和能量节点。
- 尾刃额外叠加低透明度 Additive 层，在高光与 Bloom 下形成骨白辉光。
- 所有纹理由 Canvas 生成，不引用外部图片。

### 动态

- 待机：呼吸缩放、头部慢速转动、耳部轻动、九尾异步摆动、眼部脉动。
- 悬停：整体轻微放大，光标变为 pointer。
- 鸣啸：约 3.2 秒包络，抬身、展尾、能量环扩散后回到待机。
- 动态只由时间与状态包络驱动，不在每帧创建新对象。

新增场景复用同一个高度函数与材质体系。大型主体必须拆为独立模块，避免全部写进控制器。

## 第一人称控制

- `W` `A` `S` `D` 相对于镜头朝向移动，`Shift` 疾行，`Space` 跃起。
- 鼠标按住拖动环视；滚轮改变视野焦距，不改变玩家世界位置。
- 相机高度约 1.72 m，移动时叠加轻微步频起伏与横向呼吸。
- 相机位置直接由地形高度、跳跃高度和步频决定，不使用可见角色模型。
- 拖拽结束且位移小于阈值时，才触发九尾或刻石的点击拾取。
- 文献面板打开时冻结移动与视角输入；关闭后恢复。

## HUD

- 左上：品牌、区域、坐标。
- 中上：罗盘与朝向角度。
- 左中：当前目标、原文提示、距九尾距离。
- 底部：WASD、疾行、视角、聚焦、跃起提示，以及速度、海拔和信号状态。
- 右下：局部雷达、九尾／天关／刻石／水泽标记与“鸣啸”按钮。
- 中心：极简准星；接近交互对象时显示 `E` 提示。
- 界面材质使用半透明深靛面板、细冷青边线和少量朱砂强调，不使用大面积实色。

## 性能预算

- 运行时只依赖 Three.js，不引入 React、物理引擎、动画库或后期框架。
- 地形约 6.2 万三角形；重复树木、岩石、草叶使用 `InstancedMesh`。
- 阴影贴图 `1024 × 1024`，仅主方向光投射；低帧率时关闭阴影。
- 像素比上限 1.5；连续低帧率时降为 1，并关闭 Bloom。
- 水面、天空、云雾、地形均使用程序化 Shader，不读取图片纹理。
- Bloom 在 70% 分辨率运行，低帧率自动回退到直接渲染。
- 加载按“地形 → 建筑 → 九尾 → 大气 → 后期”分阶段更新百分比。
- 生产构建应保持单 JS 文件在 600 kB 以下；Three.js 主包导致的 Vite 体积提示应如实保留，不以调高阈值隐藏。

## 回退与可访问性

1. WebGL 不可用或上下文丢失时显示二维青丘概念场景、原因说明和重新检测按钮。
2. 所有主要操作都有键盘入口；`Esc` 关闭文献。
3. 首次加载显示阶段标签与百分比，不让页面空白等待。
4. `prefers-reduced-motion` 下停止雷达扫描、加载环旋转与长过渡。
5. 移动端仅保留基础响应式布局；触控移动摇杆尚未实现。

## 已知限制

- 当前为程序化风格化场景，不是写实复原；没有骨骼蒙皮、法线贴图、屏幕空间反射或景深。
- 第一人称移动是地形高度贴地，不包含复杂碰撞体、攀爬和游泳。
- 更多《山海经》场景与旧资料模块尚未接入新架构。
