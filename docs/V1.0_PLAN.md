# V1.0 后续任务计划

更新日期：2026-11-12

## 目标与范围

完成桌面端 V1.0：确保现有资料与关系探索功能可靠，把青丘打磨成完整的样板场景，再统一浏览体验并完成性能与发布验收。

执行顺序：**基线验收与修复 → 青丘样板场景 → 浏览体验与视觉统一 → 桌面端性能与发布**。

- 移动端适配推迟到整体完成后，不作为本轮验收条件。
- 暂缓批量增加实体数量，优先处理原文、出处、同名实体及跨卷关系的质量问题。
- 更多 3D 场景在青丘样板验收后另行规划。
- 账户系统、后台管理和 AI 问答不纳入本轮。

## 当前基线

截至本计划建立时，已实现十八卷目录与舆图、山经路线、异兽图鉴、水系、物产、祀典、关系图谱、神话事件线、人物谱系和舆图／图谱双向定位；3D 体验仅有青丘试境。

这些属于代码实现进度，尚不能视为完成运行体验验收。最近一次本地构建因缺少 TypeScript 依赖未能执行；阶段一需先恢复构建。实体库为首批整理，并非全文穷尽录入。

### 场景审视记录（2026-11-12）

构图：主体居中，标题区与主体争抢左侧视觉重量；水面、浮岛与主体缺少叙事关系。

地形：单一草地平面加正弦起伏，没有丘、谷、远山与岩台层次，青丘缺少可识别的地貌特征。

植被：480 棵圆锥树随机撒布，尺度与疏密无变化，近景缺少草丛与岩石，远景缺少雾中层叠。

九尾狐：体量偏小，九尾为等距放射状白色圆管，缺少粗细、卷曲和前后遮挡关系，狐首特征偏弱。

光影：环境光与半球光偏亮，方向光缺少明确主光方向，没有逆光轮廓、体积雾和景深焦点。

交互：进入、点击九尾狐、文献面板、返回舆图均可用；缺少镜头引导和悬停反馈的视觉强化。

视觉方向：

- A 晨雾青绿：明亮、清透，远山层叠与湖面反光为主，适合展示山水空间。
- B 暮色金乌：暗调、强逆光，狐尾金边与山脊剪影为主，适合突出神话氛围与主体辨识度。

本轮采用 B 方向实施。用户尚未对最终视觉作明确确认，后续如需改为 A 方向，保留地形、交互与资源结构，仅替换天空、光照、雾色和材质色板。

### 实施记录（2026-11-12）

- 场景改为低多边形暮色山地：着色器天空、夕阳、远山剪影、湖面反光、台地、石阶、实例化树林与草、岩石、雾层。
- 九尾狐重做为象牙白狐身，补齐耳、眼、腿、爪和透明命中盒；悬停放大，点击打开文献面板。
- 九尾改为独立 Catmull-Rom 曲线、粗细渐变与错落卷曲，收紧整体尺度，保留九条尾的前后遮挡。
- 相机采用三分之四正面视角，保留拖动、缩放和低速自动旋转；光照使用深靛环境光、暖色逆光、冷色补光与 ACES 色调映射。
- 文献面板补充《南山经》原文链接与返回舆图按钮；二维回退场景改为靛蓝、琥珀和暖色逆光的同一色板。

### 后续场景制作标准

- 构图：主体置于视觉中心偏右，标题占据左侧安全区；主体轮廓须在 1280×800 与 1440×900 下不被标题、面板遮挡。
- 色板：夜空 `#14182a`，远山 `#303b3d`–`#3a4146`，地面 `#44523d`，暖光 `#ffc07a`，主体 `#f4ead9`；避免大面积高饱和青绿。
- 主体辨识：关键实体至少占画面高度 25%，剪影和材质对比可辨；悬停有尺度或描边反馈，点击命中盒大于可见体。
- 层次：近景草石、中景主体台地、远景山脊和雾至少三层；不使用均匀随机撒布作为唯一植被方案。
- 交互：进入、观察、选择主体、阅读文献、返回舆图形成闭环；返回后保留进入前的地点与模块状态。
- 资源预算：实例化重复植被；3D 场景按路由懒加载；首屏不加载 Three.js；阴影贴图不超过 2048，像素比上限 1.75。
